# Sawoo Plugins

Dalamud plugins for FINAL FANTASY XIV by Sayuuryi.

## Install

1. Open Dalamud Settings → Experimental.
2. Under Custom Plugin Repositories, add
   `https://raw.githubusercontent.com/Sayuuryi/SawooPlugins/main/repo.json`
   and click Save.
3. Search for the plugins in the plugin installer.

To try new versions early, right-click a plugin in the installer and turn on **Receive plugin testing versions**.

## Plugins

| Plugin | |
|---|---|
| [Sawoo Plates](https://github.com/Sayuuryi/SawooPlates) | A few extra tools for the Portrait Editor. |
| [Sawoo Boss Scaler](https://github.com/Sayuuryi/SawooBossScaler) | Change the size of ultimate bosses, phase by phase. |
